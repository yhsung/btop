# P4 app + boot + signals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `btop-app` crate: init chain, Term wrapper, signal handlers, main loop, clean_quit — and produce a runnable `btop` binary that exercises the full P1–P4 stack on Apple Silicon.

**Architecture:** New workspace member `btop-app` (zero third-party deps; path deps on all prior crates). Single-threaded: signal handlers set `AtomicBool` flags; main loop calls P3 `tick()` + input poll + `Input::process` via P1's `handle_key`. Term as a tiny singleton wrapper over `nix::termios` for testability. Headless smoke tests via trait-mocked OS boundaries (termios, signal install, env vars).

**Tech Stack:** Rust 2021, `cargo test`, `nix` for termios/ioctl (small, widely vetted, ~zero-cost).

**Spec:** `docs/superpowers/specs/2026-09-06-app-p4-design.md`

## Global Constraints

- Zero third-party deps EXCEPT `nix` for termios (read first: does `nix` support macOS arm64? — yes, `nix 0.29+` supports all btop platforms; pin to `nix = "0.29"` and `nix.feature = ["term", "ioctl", "signal", "fs"]`). `parking_lot` for flag wait? NO — use `std::sync::atomic` + `std::sync::Condvar`; no extra deps for sync.
- `cargo test --workspace --locked --offline`, `cargo clippy --workspace -- -D warnings`, `cargo fmt --check` green after every task.
- Transcribe C++ init/clean_quit order verbatim; headless tests via trait abstractions (no real termios, no real signal install in tests).
- Single-threaded throughout: no pthread, no `sigprocmask` outside the test-mockable install path.
- `btop` binary must be runnable on this M2 Max machine (headless smoke path covers the testable slice; full TTY path is the integration target).
